## 1. 已确认的目标与边界

本次统一动态基础功率、BiLSTM实际进给与切削负载预测三个模块。正式加工前进给由BiLSTM从NC和已知条件预测；原自主速度规划保留为独立对照。负载训练使用实测实际进给，正式九折验证和推理使用冻结BiLSTM预测值。软件不依赖inc文件；真实资料不全时继续软件检查，拒绝正式训练。

| 模块 | 实现方法 | 后续实施阶段的工作边界 |
|---|---|---|
| 动态基础功率 | 稳态曲线＋启动/制动事件参数＋分阶段功率与转速波形 | 开发读取、训练/标定、验证、保存加载和预测；允许使用现有空载 CSV 标定，不采用时序神经网络 |
| 实际进给 | 39维NC空间序列＋BiLSTM | 共用90轮九折，先训练并冻结；自主规划只作对照，实测标签必须独立审核 |
| 切削负载预测 | 工况调制PI-CCNVCM＋有序三分位TCN–Transformer＋确定性同位置记忆 | 完成共享执行能力和合成验收；本次不使用不完整真实数据优化三个网络 |

用户不需要手工提供基础功率模型的全部系数：这些系数由空载数据标定。用户后续需要提供的是机床运动能力、必要的坐标/刀补配置，以及未记录的刀具和工况资料。

原始数据只读。软件不得将假设参数保存成真实机床参数，不得将随机初始化网络的输出展示为有效预测。不自动提交、推送或构建替换已有 EXE。

## 3. 数据入口、界面和模块组织

### 3.1 统一数据流程

```text
空载CSV → 通道/单位审核 → 开发/冻结确认 → 两种基础功率接口分别验收
NC＋机床几何配置＋已知条件 → BiLSTM → 预测实际进给与程序位置
工艺＋物理工况＋实际进给 → 正值物理主趋势 → 三分位路径残差 → 同位置记忆
实测CSV＋实测转速接口已验证的基础模型 → 实测切削标签 → 质量/对齐 → 固定样本快照
快照 → 每折进给/主趋势/残差三阶段 → 九折选择 → 全90轮重新初始化训练 → 独立验证
```

读取成功、位置对齐成功、质量校验通过和可进入训练是不同状态，分别记录。未来加工的实测功率、实际进给、振动和报警不得成为加工前预测输入。

### 3.2 共用读取和对齐服务

- 根据 `ChannelInfo` 的信号名称、轴名和寄存器号识别通道，不绑定固定列号。
- 支持当前中文编码、空行和尾逗号；新代码、配置和派生文本使用 UTF-8 无 BOM。
- 按 CSV 规则读取 W、r/min、mm/min 和当前 1 ms 采样间隔；位置比例、程序行号偏移需用 NC 核验。
- 模型计算时单独进行 `/60`、`/60000`、`/1000` 等量纲换算，不再按通道中的 `10`、`360` 二次缩放。
- 原始负功率、转速和轴速度保留；异常值只添加标记，不静默截零或删点压缩时间。
- 按轮次目录、文件名和 90 轮映射表检查程序、工况与文件配套关系。
- 对齐使用程序版本、执行实例、物理行号和段内累计行程；处理坐标平移，不跨程序行插值。重复循环、停留和同位置多值必须消歧。
- 使用分块读取和按需加载；批量检查不把所有加工文件同时载入内存。

### 3.3 研究版界面与后台服务

保留现有主页面、PIT及基础功率研究入口。网页与命令行共用TrainingService/JobService，提供清单检查、快照准备、候选配置、任务确认、训练监控、模型管理、预测及评价。原桌面四个工作区继续提供研究功能：

1. **数据检查：**选择实验根目录，查看轮次清单、文件缺项、通道与单位、配套状态和原始曲线。
2. **基础功率：**导入空载 CSV，查看平台/变速事件，编辑估计转速指令，执行训练/标定，查看验证、保存加载及预测曲线。
3. **指令进给：**选择机床配置与 NC，填写参数，生成路径和指令进给，查看限制来源、预计时间及可选对照。
4. **负载模型：**配置刀具/工况和模型结构，检查输入，显示主趋势/残差/记忆状态，准备分组样本；正式训练按钮由完整90轮、质量、配套及基础模型资格共同决定；不能仅靠前端按钮状态放行。

耗时读取、标定和规划使用后台任务，支持取消；UI 控件和画布更新回到主线程。取消或失败不覆盖上一个有效模型。

新计算核心放在 `src/project/load_prediction/`，不与界面代码混写。模型和机床配置使用独立版本；外部数据路径由配置或文件选择器传入。输出统一写入项目输出目录，机床配置与模型包可独立导入导出。

## 4. 动态基础功率模块

### 4.1 可标定的非神经事件模型

采用稳态曲线、事件参数与四阶段波形，不再用一组固定升降速系数和一个功率时间常数拟合所有档位。

- 稳态曲线：提取稳定窗口末段功率，同档位按文件等权汇总，再做分段线性插值。
- 事件参数：从每次完整的启动或制动中辨识峰值/谷值、达峰/谷时间、最终稳态功率、恢复稳态时间。
- 四阶段波形：起点到极值、快速恢复、缓慢接近稳态容差带、容差带内收敛。每阶段保留低维归一化形状；恢复段使用单调包络，避免把电气纹波当成模型动态。
- 同时标定各阶段转速形状，支持从目标转速生成预计转速与基础功率。
- 目标档位间使用线性插值，不外推；启动与制动分开拟合，保留负功率。

### 4.2 数据与时间定义

保留现有CSV读取、自动平台识别与人工审核入口。`command_time_s`自动值实际为观测响应起点，来源仍为`estimated`，不能声称采集了真实S指令时刻。单次查询默认从已经稳定停转启动；制动查询则指定已稳定初始转速和目标0。

恢复稳态定义为：功率进入最终稳态功率的±max(5 W, 5%×|Pss|)范围，并持续至少0.5秒。输出同时包含从响应起点到稳态的时间，以及从峰值到稳态的时间。上述容差、持续时间和信号平滑窗口均通过标定配置保存。事件未完整恢复时标为右删失，不将记录结束时刻作为恢复时间。

### 4.3 验证与保存

三份空载记录轮流留出，先划分文件，再使用训练文件拟合稳态曲线、事件参数与波形；留出功率只用于评分。验证分别报告稳态误差、完整过渡段误差、极值误差、达峰/谷时间误差和恢复稳态时间误差。另保留与旧版相同时间窗口的动态RMSE，支持可比评估。

开发默认验收：事件峰值/谷值误差不超过事件功率幅值的25%（分母下限50 W），达峰/谷时间误差不超过0.15秒，恢复稳态时间误差不超过0.5秒，稳态代表功率误差不超过15 W；完整过渡段RMSE优于仅用稳态曲线，并满足覆盖要求。分别显示各项状态，任何必要项失败则整体仍为待验证候选，不能用于正式负载网络训练。

模型同时保存重复事件的实测最小/最大值，作为变化范围而非置信区间。该范围在中间转速处也只作插值，不代表独立验证。新模型格式为`afc.base.2`；`afc.base.1`继续支持加载及原算法预测，单次事件参数查询需要重新标定。取消或失败不覆盖已有有效模型，待验证候选可单独查询和保存。

### 4.4 加工后扣除与加工前预测

- 加工后：用实测转速识别事件起点和目标平台，重建基础功率后计算`P_cut=P_spindle-P_base`。不从加工功率中反推基础功率；负值保留。
- 加工前：从NC时间线得到主轴启停事件，使用已标定的事件功率与转速波形生成预测。没有控制器延迟数据时，明确标记暂按零延迟对齐，不能声称绝对时间已验证。
- 仅支持当前机床、相同升降速设置及已覆盖状态的稳定0→S、稳定S→0。非零转速直接切换、尚未稳定的连续切换、超范围、实测变速持续时间明显偏离标定记录时，标记无效并给出原因。
- 初态未知、记录在变速中途开始或结束时，保留无效区间；不虚构完整事件。

当前验证结果及候选模型使用方法见《动态基础功率事件模型验证.md》。

### 4.5 可选空载参考与重复性检查

已增加独立的同会话空载参考：从预测前已经完成、明确确认无切削的稳态窗口中提取功率偏移，按一个与转速成比例的参数校正单次事件查询。参考单独保存，检查有效性、范围和模型版本；不自动改动切削标签或整程序预测。没有参考时沿用原来的目标转速查询。

对重复空载事件同时报告恢复时间范围，以及仅转速单值预测在现有记录上的最小可能最大误差。保留原精度标准，区分模型拟合问题与相同输入下的重复性限制。双指数恢复候选经比较未改善原时间误差，未替换现有事件模型。验证与边界详见《动态基础功率空载参考校正.md》。

## 6. 切削负载预测模块：三阶段能力与真实证据分开验收

### 6.1 PI-CCNVCM 主趋势

`F_in`在负载训练中取实测实际进给，在正式验证/推理中取冻结BiLSTM预测实际进给。输入局部切削状态 \(v_c/v_{c0}\)、\(f_z/f_{z0}\) 和工况编码，系数网络输出正值 \(K_s^{(0)},K_e^{(0)}\)，物理层计算：

\[
P_{\mathrm{phy}}^{(0)}
=\frac{K_s^{(0)}MRR}{1000}
+K_e^{(0)}v_cL_{\mathrm{eq}}
\]

其中 \(MRR=a_pa_eF_{in}/60\)，\(v_c=\pi DS/60000\)，\(f_z=F_{in}/(zS)\)，最终功率为 W。

实现系数网络、可微物理层、正值约束、损失计算、冻结和保存加载。网络层数和宽度可配置，正式选择仍由未来 90 轮分组验证决定；小型测试网络只检验程序结构，不作为最终配置。

主趋势未来只使用稳态、转速稳定、刀具健康、无报警、数据完整且可靠对齐的样本。质量字段缺失时标为未知，不能默认合格。机床、刀具、工件材料、装夹、冷却五个物理分支使用训练组归一化/类别词表和缺失掩码；不学习任意ID。单水平分支冻结，参考主趋势倍率为1、残差倍率为1、偏置为0。完全共变因素只解释组合效应。独立目标数据可在全部网络冻结后先标定Ks/Ke正倍率，再固定主趋势标定残差倍率/偏置，并单独验证。

### 6.2 多尺度 TCN–Transformer 路径残差

输入严格限定为六类：

\[
\left[\widetilde P_{\mathrm{phy}},a_p/D,a_e/D,
F_{in}/F_0,|\kappa|D,\ell_{\mathrm{block}}/D\right]
\]

TCN 提取局部变化，Transformer 处理较长路径关系，输出q0.05、q0.50、q0.95三个有序残差分位数，中位数允许正负。目标为 \(P_{\mathrm{cut}}-P_{\mathrm{phy}}\)，最终恢复到W后与主趋势和同一历史记忆相加，形成直接名义90%区间。独立整组区间校准是可选后处理，不能用测试集校准。

未来采用全部有效切削段，包括稳态、进退刀、曲面、斜面、台阶和过渡段。残差训练时冻结主趋势，不联合微调；主趋势版本改变后，必须重新生成残差标签并重新训练匹配的残差模型。

### 6.3 同位置记忆

按“程序版本＋参数组＋程序行号＋段内行程网格＋刀具使用会话”维护状态。存在重复执行时再区分执行实例。

仅用两个网络预测之后的剩余误差更新；第k次预测只能使用真实采集时间或已审核事件顺序中此前完成的记录；计划轮次不冒充真实先后顺序。冷启动为零，根据位置匹配与重复性进行确定性可靠性控制，不增加门控神经网络。

程序/参数/刀具使用会话变化、报警、缺失和对齐失败时暂停或重置。网络版本改变时重置或基于历史数据重新计算记忆，不能把旧模型残差直接叠加给新模型。

### 6.4 统一训练入口与防泄漏

软件支持以下完整流程；本次只运行合成软件验收，不执行不完整真实切削数据的网络训练：

```text
按experiment_protocol.py的明确轮次表建立9折，每折80轮训练/10轮验证
→ 每折只从训练组生成预处理参数
→ BiLSTM训练并冻结
→ 使用实测实际进给训练主趋势并冻结
→ 生成该版本残差标签
→ 残差训练并冻结
→ 使用预测实际进给进行端到端验证
→ 按RMSE、MAE、高负载低估率依次选配置
→ 全90轮重新初始化，各阶段轮数取九折最佳轮数中位数向上取整
→ 在独立15轮中按真实事件顺序评价同位置记忆
```

同轮全部文件及窗口属于同一集合。每轮、每类加工特征分别统计后等权汇总。归一化和异常阈值只由训练组计算。

90 轮齐备后，按实验方案选择统一配置、重新初始化并综合训练；另外3个代表程序×5轮记忆验证和3个新零件程序×5轮冻结测试不加入网络训练。相同NC的独立重复采样允许跨开发折，同一采样内容及同轮五类文件/窗口不能跨折。

当前可用的三十余轮用于格式检查、对齐和样本准备，不冒充已经完成 90 轮交叉验证。本期不执行真实数据的三个网络优化器更新；合成短程优化仅验证训练链路，权重独立标记且不进入正式模型列表。

## 8. 实施阶段与验收

| 阶段 | 主要交付 | 验收标准 |
|---|---|---|
| 1. 数据与基础架构 | 共用读取器、清单、单位与位置审计、界面框架 | 能发现并检查现有 3 份空载和 163 份加工 CSV；准确报告缺项；不修改原始文件 |
| 2. 空载标定模块 | 事件审核、稳态曲线、动态功率和主轴响应辨识 | 完成整文件留出验证；标记估计指令来源；保存加载结果一致；失败不覆盖有效模型 |
| 3. 自主指令进给 | 机床参数配置、NC 解析、约束规划和图形显示 | 无 inc 也可工作；真实参数可后填；合成程序满足约束，当前 NC 支持/缺项有清单 |
| 4. 负载模型实现 | 工况主趋势、三分位残差、记忆、低维校准及共享训练 | 物理单位、冻结、九折和模型版本正确；真实训练由数据资格拦截 |
| 5. 联调与交付 | 研究版功能页、接口文档、验收报告、下一步数据清单 | 可完成数据检查、空载标定和有配置的进给生成；未训练/缺配置状态展示准确 |

按上述顺序推进，每阶段报告修改和实际验证结果。参数或配套文件缺失仅阻止相应真实案例验收，不阻止独立模块继续开发。

### 自动化与真实文件检查

- **CSV：**列序变化、空载/加工格式、中文编码、缺列、异常数值、尾逗号、负值、时间索引与重复缩放；真实文件原始内容校验值不变。
- **基础功率：**用已知参数生成的合成响应检查公式和辨识；用真实三个文件检查留出误差；覆盖升速、降速、平台、停机、状态未知和超范围。
- **指令进给：**直线、圆弧、螺旋、短段、拐角、模态省略、强制停顿、坐标配置缺失和不支持指令；检查各轴速度/加速度/跃度及轮廓误差。
- **主趋势：**已知系数的物理计算、单位转换、无接触状态、输入缺失及可微性；合成梯度/短程优化检查不生成正式权重。
- **残差：**六维特征、正负输出、窗口边界和补齐掩码、主趋势冻结、标签版本匹配。
- **记忆/划分：**冷启动、未来轮次拒绝、跨工况/换刀重置、同轮不跨折、同一文件窗口不泄漏。
- **界面/兼容：**新增功能仅研究版显示，后台任务可取消，未训练无正式预测曲线，原有主页面、PIT、区间划分和发布入口回归检查。

测试在 Conda AFC 环境执行；新增神经模型依赖独立声明并按需加载，读取、空载标定和进给规划不因缺少神经网络依赖而无法启动。不在计划制定阶段安装依赖或执行标定。

## 9. 文档同步、原则与后续数据

### 文档同步

现行方法以2026-10-09统一规范及90轮实验方案为准；下列规则用于同步代码、网页和论文计划：

- 动态基础功率采用稳态插值与动态参数辨识，不采用时序神经网络；原公式保留为历史/对比方法，不同时宣称两套实现均为现行主方法。
- 正式加工前负载进给来源为BiLSTM，负载训练来源为实测实际进给；自主规划和inc只作独立对照。
- 90轮按明确S×T表九折，依次冻结BiLSTM、主趋势和残差，独立15+15轮不用于模型选择。
- 新模块属于研究版新增功能，不把旧发布版固定空载值和 Kc/Ke 反解公式直接套入新模型。

本计划保留早期实现史；2026-10-09同步统一规范、实验方案与论文1计划，技术方案Word/PDF按交付报告说明其实际更新状态。

### 工程原则

- **KISS：**基础功率先用插值与低阶模型，界面围绕导入、配置、检查和结果展开。
- **YAGNI：**先覆盖当前实验 NC 和数据范围，不扩展为通用五轴控制器，不提前训练负载网络。
- **DRY：**通道读取、单位、位置对齐、文件清单和版本信息共用一套实现。
- **SOLID：**读取、标定、规划、主趋势、残差、记忆与 UI 分别承担明确职责，通过数据接口组合。

### 需要逐步补齐的资料

1. 机床轴速度、加速度、跃度、插补周期及路径平滑容差；可以在模块开发后填写。
2. 涉及回零、坐标变换、刀补、主轴等待和暂停的具体机床配置。
3. 其他加工特征对应的工艺信息和缺失 CSV，以及刀具齿数、工况、健康状态、报警等质量记录。
4. 后续完整 90 轮及独立验证数据；这些是正式负载训练/评价条件，不是现在开发的前提。

软件阶段已具备统一执行能力。下一步补齐90轮及工艺/质量资料、修复并独立确认基础功率实测转速标签接口，再按冻结协议正式训练三个网络。事件查询通过不能替代标签接口验收。
