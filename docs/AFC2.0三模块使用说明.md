# AFC2.0 三模块使用说明

2026-10-09更新：研究网页、命令行和共享后台现行操作以[AFC2.0负载预测统一实施与使用规范](AFC2.0负载预测统一实施与使用规范.md)为准。本文保留桌面基础功率及自主规划的操作和历史结果，历史测试数量不代表本次验收。

本功能位于**研究版 → 负载预测**，新增数据检查、基础功率、指令进给、负载模型四个工作区。发布版仍只有原来的主页面。

2026-09-28 新增“一阶/二阶联合辨识对比、灰箱候选转速查询、加载灰箱候选、灰箱标定设置”。已用三份空载记录验证，二阶惯性灰箱优于同类一阶，但没有全面超过事件模型；候选独立保存，不自动替换当前基础模型。操作、结果及接口见[动态基础功率灰箱联合辨识](动态基础功率灰箱联合辨识.md)。

## 1. 启动与依赖

在项目根目录运行：

```powershell
conda activate AFC
python src/project/main.py
```

基础计算使用 NumPy、Pandas、SciPy；神经模块按需加载 PyTorch。CPU版安装命令：

```powershell
python -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
```

2026-09历史开发曾在AFC安装CPU PyTorch 2.7.1；2026-10-09本次未安装或升级依赖，未训练真实切削网络。独立依赖清单位于 `requirements-load-prediction.txt`。

Windows Conda MKL 与 CPU PyTorch 可能加载不同的 OpenMP DLL。应用在 NumPy 初始化前默认选择 `MKL_THREADING_LAYER=SEQUENTIAL`，避免进程退出；不启用不安全的重复运行库选项。在已经提前导入 NumPy 的外部宿主中，如果提示线程版MKL已加载，应设置此环境变量后重启进程。该设置使MKL使用单线程，可能降低大型矩阵任务速度。

## 2. 操作流程

### 数据检查

选择实验根目录，默认检查文件头、轮次、通道、90轮映射和NC配套；勾选“逐点检查”后扫描全部样本。CSV规则、物理单位换算和网络归一化相互独立。

2026-09历史盘点有3份空载、163份加工CSV，共33个轮次目录。R01未找到CSV，R10缺斜面、R15缺台阶；这只是文件状态。两份实验映射表是普通CSV，不作为采样文件解析。备份扩展名不参与导入。

实测文件存在两种通道配置：109份文件重复记录Z轴速度、提供指令XYZ位置；54份提供实际XYZ位置。读取器保留重复通道，在分块读取时比较数值；一致时提供统一字段，冲突时统一字段为NaN并报告。功率、主轴转速或程序行号的重复冲突还会使该采样点无效。实际位置缺失时，对齐明确使用采集的指令位置，并在样本元数据中记录 `position_source=command`；不会把它标成实际位置。

### 动态基础功率

1. 导入三个空载CSV，自动识别平台与事件；“审核平台/指令”可以修正窗口、标称转速和事件起点。
2. 点击“训练/标定”，执行稳态曲线、启动/制动事件参数与分阶段波形标定，并进行整文件留出验证。不使用时序神经网络。
3. 点击“转速查询：峰值/时间”，填写目标转速，初始稳定转速默认为0；无需G代码或机床运动参数，即可获得单次启动曲线、峰值、达峰时间、最终稳态功率、进入稳态时间及峰值后的恢复耗时。制动查询时目标填0、初始填稳定转速，输出明确称为制动谷值。
4. 查询显示当前候选状态、各指标验收情况及重复事件实测范围。范围不是置信区间；未通过验收的结果只作候选估计。
5. “保存候选/当前模型”保存最近标定的候选；失败候选不会替换加工后扣除等流程中已有的有效模型。“加载基础模型”明确选择要使用的模型。
6. “查看扣除结果”使用实测转速生成基础功率，显示切削功率并保留负值。“加工前基础功率”使用已配置NC时间线生成事件预测，显示未标定控制器延迟等假设。

可选完善：点击“导入空载参考（可选）”，选择同一会话、预测之前已经完成的稳定空载窗口，提取至少1秒的参考。之后的单次查询可按当前平台功率修正；参考与原模型分开保存，不自动应用于加工后标签或整程序预测。模型变化后参考失效。查询同时显示重复记录对单值恢复时间预测的限制。操作、条件留出结果及边界见[空载参考校正](动态基础功率空载参考校正.md)。

事件模型为稳态插值与四阶段波形：极值前、快速恢复、缓慢接近稳态、容差带内收敛。恢复段采用单调包络，不复现电气纹波。新标定不再使用全转速共用的动态系数与单一功率时间常数。

“进入稳态”指进入最终稳态功率±max(5 W, 5%×|Pss|)并保持至少0.5秒；“达峰时间”和“进入稳态时间”均从观测响应起点计时。“峰值后恢复耗时”是两者之差。没有真实S指令时间戳，不能把这些时间直接解释为从下发指令开始的时间。

已覆盖的启动/制动档位为3000、4000、5000、6000、7000、8000、9000、9500、10000 r/min。中间档位可以插值，但尚未独立验证；范围外不外推。只支持已稳定0→S和已稳定S→0。非零转速直接切换、未稳定重启和明显不同升降速设置均标记无效。记录起始为未知旋转状态时先屏蔽保守恢复窗口；无法识别目标平台的截断变速也保留无效标记。

开发验收分别检查峰值、达峰时间、稳态代表功率和恢复时间，并比较完整过渡段与稳态曲线的误差。所有必要项通过才标记`validated_in_sample_domain`；这不是生产精度认证。2026-09历史候选峰值和达峰时间通过，恢复时间和个别稳态偏差未通过，整体为`calibrated_unvalidated`。2026-10-09新增五轮按1—3开发、4—5冻结确认；事件指标通过，但实测转速标签接口覆盖约95.43%，仍不能作为正式负载样本的基础模型凭据。详见[事件模型验证记录](动态基础功率事件模型验证.md)。

旧版`afc.base.1`仍可加载及预测；新增事件查询需要`afc.base.2`。`fit_period_s/max_nfev`等旧辨识配置保留兼容，新事件标定不使用这两个参数。旧版JSON中的动态系数字段在v2中仅为格式兼容占位，不能当作v2辨识结果。

### 自主指令进给对照

本工作区输出保留作研究对照。正式负载加工前进给改用独立训练的BiLSTM，参见《BiLSTM实际进给模块》。

先填写“机床参数”，可暂时留空并保存。XYZ速度单位为mm/min，加速度为mm/s²，跃度为mm/s³；插补周期以秒填写，不从CSV的1ms采样周期推断。

高级设置按NC实际涉及功能填写：

- `work_offsets_mm`：例如G54的XYZ偏置；`tool_lengths_mm`：H编号对应的刀长。
- `home_position_mm`：机床参考点；`fixed_rotary_degrees`：已核验的固定A/B/C角度。
- `manufacturer_semantics`：G05.1核验后可设为`contour_tolerance`；G43.4仅在已确认固定刀轴等价刀长补偿时设为`fixed_axis_length_compensation`。G04需要确认秒单位才可设为`seconds`。
- `optional_stop`：`skip`表示已确认忽略M01；否则使用明确的暂停时长。未配置的人工暂停或主轴等待使整程序时间线标为不完整。
- `provenance`：填写真实参数来源；软件测试参数必须标成`test`或`synthetic_test_only`。

算法使用经过轮廓误差检查的连续空间样条、前后向速度约束、跃度约束传播和S形速度时标，最终逐轴检查速度、加速度、跃度和行程。几何细分与速度规划网格分开，普通短程序段之间不强制停到零速；快速/切削模式切换、暂停和回零按独立过程处理。

首版只支持固定刀轴XYZ、G17平面圆弧/螺旋及当前实验所需指令。支持常数宏变量赋值和引用，不支持通用宏控制流；当前曲面程序的特定三行“零偏检查→PRINT→ENDIF”只作为无运动作用的诊断注记，不执行文件写入。未知宏或联动定位到物理行并阻止有效计划生成。前瞻首版为全程序。

输出是**自主规划估计**，可能比真实控制器保守。测试参数下的NC验算只能证明软件处理与约束检查可运行，不能作为真实机床的加工时间或进给准确性结论。inc不属于必需输入。

### 负载模型与样本

- “检查模型结构”不训练。正式网页通过清单、快照、候选、任务预览后调用共享后台；资格不足时返回逐项原因，真实90轮资料未齐时不能绕过检查。
- 正式“准备加工前特征”只需NC、明确的机床几何配置、工艺、刀具/物理工况及匹配BiLSTM，使用预测实际进给；不读取未来实测CSV。旧进给规划入口仅作预览。
- “准备单轮样本”另外选择实测CSV和基础模型，填写轮次、组合、工况及质量信息，生成候选训练样本。`null`表示未知，不能当作质量合格；稳态程序行需经过审核。
- 基础功率页启用“应用当前空载参考”后，单轮样本会使用校正后的基础功率，并导出校正量及参考来源。跨文件使用须填写同一会话内的目标时间原点；同文件参考及其之前的样点屏蔽。参考校正仍为候选，不能据此自动打开网络训练。详见[空载参考校正](动态基础功率空载参考校正.md)。
- 支持当前“序号 N ap ae F MRR s S G”工艺TXT，其中`s`按累计行程、`N`按一基物理行读取；行号偏移必须显式填写。标准工艺CSV字段为`line, execution_instance, segment_mm, ap_mm, ae_mm, steady`。
- 对齐逐程序行/执行实例进行，消除一份记录的统一坐标平移，不跨行插值。停留、同位置多值、长度不匹配或访问次数不一致会留下缺项，不自动生成虚假标签。
- 无训练权重时拒绝正式预测。匹配afc.load.3模型输出主趋势、残差、记忆、切削q05/q50/q95；默认是路径域切削功率。完整时间映射、等待和基础模型证据缺失时返回total_power_unavailable。
- 同位置记忆初始为零，默认至少两轮重复才产生修正，按重复误差方差确定可靠性；预测第k次只用真实采集时间或已审核事件顺序中此前完成的记录。完成预测后才可用健康、无报警、完整、可靠对齐的该轮实测误差更新；程序、参数组、刀具会话或网络版本变化时使用不同记忆键。

## 3. 开发接口与文件

基础功率现另有“恢复尾段对比”“恢复候选查询”“加载恢复候选”三个研究入口。候选支持随转速变化的恢复时长或指数尾段，以及同会话中此前已完成的空载参考；本轮比较尚未通过全部阈值，保持候选独立。具体结果、参考输入和复现命令见[动态基础功率恢复尾段对比](动态基础功率恢复尾段对比.md)。

计算核心位于 `src/project/load_prediction/`，不依赖按钮回调。公开接口从 `project.load_prediction` 导入：

| 接口 | 结果 |
|---|---|
| `inspect_dataset / read_measurement` | 数据清单、标准测量记录和质量信息 |
| `fit_base_power` | 基础功率模型、主轴响应参数及整文件留出报告 |
| `predict_base_from_measured_speed / predict_base_from_commands` | 加工后或加工前基础功率 |
| `predict_base_event` | 单次启动/制动曲线、峰值/谷值、达峰/谷时间、稳态功率、恢复时间和实测变化范围 |
| `calibrate_idle_reference / assess_repeatability` | 提取已确认的先前空载参考；检查仅转速单值预测的时间重复性限制 |
| `parse_nc / plan_feed` | 可预览几何与缺项，或有效的自主进给估计 |
| `prepare_forward_features` | 不依赖实测的加工前特征 |
| `prepare_load_samples` | 候选标签、质量筛选和位置键 |
| `build_load_models / load_models / predict_cutting_power` | 未训练结构、模型加载、经过状态检查的预测 |

`BasePowerModel`、`MachineConfig`、`FeedPlan`和`PositionMemory`支持JSON保存加载；神经模型包使用PyTorch `weights_only=True`加载，包含状态、配置、归一化和匹配版本。写出的文本统一UTF-8无BOM。原始CSV不写回，论文 1 的派生结果默认保存在 `data/paper1/`。

## 4. 共享训练、预测与网页

```powershell
conda activate AFC
$env:MKL_THREADING_LAYER = 'SEQUENTIAL'
python scripts/load_prediction.py protocol
$env:PYTHONPATH = 'src'
python -m project.load_prediction.web_service --port 8765
```

在浏览器访问`http://127.0.0.1:8765`，按清单检查、样本准备、候选配置、任务预览、启动任务、模型管理和加工前预测的顺序操作。网页和CLI共用TrainingService/JobService；浏览器关闭不取消后台任务。任务状态、损失、进度、错误和取消结果持久保存。重启服务后中断任务明确标记，不能冒充完成。

开发集90轮×五类共450个有效位置，按唯一协议的九种S×T组合每折80训练/10验证。同轮全部文件/窗口保持同折；同NC独立实测允许跨折，重复采样内容拒绝。归一化与质量阈值仅由训练组计算。

每折依次训练并冻结BiLSTM、主趋势、路径残差。负载训练使用实测实际进给，验证使用预测实际进给；负载误差不回传BiLSTM。按RMSE→MAE→高负载低估率选择后，全90轮重新初始化，各阶段训练轮数取九折最佳轮数中位数向上取整。独立3程序×5轮记忆验证和3新零件程序×5轮冻结测试都不参加选型。

五类物理工况分支使用真实描述、训练词表/尺度和缺失掩码。单水平因素冻结为中性参考，多因素完全共变只报告组合效应。少样本目标适配冻结所有网络，先拟合Ks/Ke正倍率，再拟合残差倍率/偏置；适配集、适配验证集及最终测试分别登记并排重。

残差直接输出有序q0.05/q0.50/q0.95，名义90%区间不依赖额外校准器。报告覆盖、宽度、区间分数和高负载上界超出率；可选校准仅使用独立完整分组。详见统一规范中的完整字段、公式、CLI请求和版本要求。本次没有开展真实90轮训练或把合成模型写入正式模型列表。
