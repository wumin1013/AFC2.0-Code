# 动态基础功率：可选空载参考校正与时间重复性

日期：2026-09-28。本次保留事件模型及原验收阈值，增加可选的会话参考，不训练神经网络。

## 峰后双指数尾段比较的结果与边界

将启动峰值后的恢复拟合为快、慢两个指数分量，分别按文件留出后，原恢复时间标准下的最差误差约为2.77秒；当前事件模型相应误差约为2.16秒。双指数模型没有改善目标指标，因此没有替换现有模型。比较参数与结果已保存在验证输出目录，拟合方法可通过验证脚本重现。

这里比较的是逐事件尾段拟合后汇总参数，并不是完整的多文件共享状态空间辨识，不能据此否定所有二阶方法。后续已增加共享参数与运行初态的完整一阶/二阶灰箱比较，结果见[动态基础功率灰箱联合辨识](动态基础功率灰箱联合辨识.md)。

数据还给出了更直接的限制：9500 r/min下，三次采集的恢复时间约为6.089、7.644、8.847秒。对于相同输入，只输出一个固定值的模型，其最小可能最大误差为：

\[
\min_c\max_i|c-t_i|=\frac{\max_i t_i-\min_i t_i}{2}=1.379\ \mathrm{s}
\]

因此，只用目标转速，无法同时使这三次结果都满足0.5秒误差要求。这个结论只针对现有重复记录、相同输入和单值预测，不等于加入机床状态后仍不可预测，也不是未来置信区间。代码新增重复性检查，查询已采集档位时显示该限制；中间插值档位不伪造实测重复性结论。

## 已加入的完善方法

利用**同一会话、预测事件之前已经完成的稳定空载平台**，提取最后至少1秒的转速和功率，估计一个功率平台偏移：

\[
b=\frac{P_{\mathrm{ref}}-f(S_{\mathrm{ref}})}{S_{\mathrm{ref}}/1000},\qquad
\Delta P(t)=b\frac{S(t)}{1000}
\]

其中b的单位为W/(1000 r/min)。该修正用一个与转速成比例的偏移近似当前会话的功率平台差异，不将其称为已辨识的温度或磨损模型。零转速功率保持原值；启动和制动功率保留正负。

**现已接入单次事件查询、加工后扣除、整程序预测及候选样本准备。**参考独立保存，不写进原基础模型；使用时必须绑定机床、连续运行会话及共享时间轴。校正结果仍是研究候选，不自动放行正式训练。操作、接口和本轮复核见文末“会话参考集成”。

本次只修正功率，不根据一个平台功率值推断恢复时间。原始标定范围仍按原数据展示，不能把它当作校正后的条件区间。带参考的结果明确标为`reference_adjusted_candidate`，不继承原模型的验收结论。

## 条件留出验证

每折使用另外两份空载文件建立事件模型。对被留出的文件，只用其**首个已完成3000 r/min平台的末1秒**提取参考，然后预测后续4000～10000 r/min事件。参考平台自身及对应制动不计入预测成绩，目标事件的功率不参与校正。

这是“已有一段参考数据”的条件验证，不能替代完全不读取留出功率的盲测。三个文件均来自现有空载采集；没有新增加工训练数据，也未做网络优化器更新。

| 留出文件 | 原稳态代表功率MAE/W | 参考校正后MAE/W | 原最大偏差/W | 校正后最大偏差/W |
|---|---:|---:|---:|---:|
| 第1份 | 11.89 | 2.80 | 16.10 | 8.32 |
| 第2份 | 3.39 | 1.30 | 4.75 | 5.13 |
| 第3份 | 8.49 | 1.79 | 11.35 | 3.18 |

三折平均误差均下降，全体后续档位的最差稳态偏差由16.1 W降至8.32 W。第2折的单个最差值略有上升，不能表述为每个预测点都改善。这些是稳态代表功率误差，不是完整曲线逐点RMSE。

恢复时间误差仍未通过原标准，整体仍不能宣称完成真实机床精度验收。当前方法的价值是改善平台偏移，并明确区分“功率误差”和“恢复时间可重复性”。

## 界面使用

1. 在研究版“负载预测 → 基础功率”中加载或标定事件基础模型。
2. 可直接点击“转速查询：峰值/时间”，得到原来的仅转速估计。
3. 若有同一会话的加工前空载记录，点击“导入空载参考（可选）”。选择已完成的CSV，并选择至少1秒的稳定窗口；界面默认使用最后一个正转速平台的末1秒，可自行更改。
4. 确认窗口不含切削后提取参考，再进行之后的单次事件查询。
5. 参考可独立保存、加载或清除。重新标定或加载模型后自动清除参考；旧参考与新模型版本不匹配时拒绝使用。

## 会话参考集成（2026-09-29）

研究版“负载预测→基础功率”新增“应用当前空载参考”和“参考会话设置”。从CSV提取时可选择平台，再填写机床标识、连续运行会话标识和文件时间原点。默认选择首个正转速平台的最后1秒，仍须通过稳速、漂移及纹波检查。无须为此填写XYZ运动参数；这里的机床标识仅用于防止不同机床误用参考。

`time_origin_s`表示该文件0秒在同一会话时钟中的位置。例如参考文件从会话第0秒开始，其参考结束于第12秒；若加工CSV从会话第60秒开始，目标文件的时间原点填60。不得因两个CSV都从0开始就把它们当成同步采集，也不从文件名、排序或修改时间猜测先后。

- 同一来源文件自动沿用参考的时间原点，并验证参考窗口指纹。参考窗口及此前样点不用于该参考下的扣除标签，而是标记无效。
- 不同文件、NC计划或新事件需要填写目标时间原点，并核实同机床、同一连续会话。目标必须晚于参考完成；未知时间、会话不符、模型版本不符均拒绝应用。
- 清除/切换参考、加载或重新标定基础模型时清除旧候选样本及上次预测；修改或加载机床配置也清除参考。软件无法自行检测物理机床重启，发生重启或工况变化时应重新提取参考。
- 旧参考JSON继续可读，缺少会话信息时不会在界面自动启用，可按真实记录补齐或重新提取。旧的无会话单次波形API保留为离线研究查询，不可用于整段预测与切削标签。
- 图中可同时查看校正前后基础功率；负功率及负切削标签保留。耗时操作沿用后台取消及失败保留结果机制。

接口增加可选关键字参数，原来不传参考的调用方式保持兼容：

```python
session = {"machine_id": "实际机床标识", "session_id": "本次连续运行标识", "time_origin_s": 0.0}
reference = calibrate_idle_reference(
    idle_record, model, start_s=10.0, end_s=11.0,
    no_load_confirmed=True, session=session,
)
target_session = {**session, "time_origin_s": 60.0}  # 示例，须按真实时间填写
result = predict_base_from_measured_speed(
    cutting_record.time_s, cutting_record.values["spindle_speed_rpm"], model,
    reference=reference, session=target_session, record_source=cutting_record.source,
)
samples = prepare_load_samples(
    process, plan, cutting_record, model, metadata,
    reference=reference, session=target_session,
)
```

`predict_base_from_commands`同样接收`reference/session/record_source`。带会话的`predict_base_event`还需要`onset_s`（目标来源自身时间轴上的事件响应起点）。原单次事件接口保留分阶段包络约束；整段接口按实测或预计转速执行`ΔP=bS/1000`，不重新辨识恢复时间。

样本准备接口及界面在同文件复用时核对参考窗口；只接收时间、转速数组的底层接口无法验证功率窗口，直接调用者须确保来源真实，必要时先调用`verify_reference_record`。

样本CSV新增`base_power_w`、`base_reference_correction_w`；配套元数据记录基础模型版本、校正预测版本、完整参考、目标会话和状态。`reference_adjusted_candidate`不会继承基础模型的已验证状态，主趋势与残差训练掩码仍关闭。

## 本轮复核

仅原三份空载记录、保存的整文件留出基准，每份使用已完成3000 r/min空载平台作参考，评价后续24个启动事件：

| 指标（同一组24事件等权平均） | 校正前 | 校正后 |
|---|---:|---:|
| 稳态代表功率相对误差 | 3.88% | 0.85% |
| 稳态代表功率MAE | 7.93 W | 1.96 W |
| 稳态段逐点WAPE | 4.25% | 2.11% |
| 稳态段逐点MAE | 9.19 W | 4.71 W |

逐点指标由接入参考后的指令预测接口生成，使用原始1 ms数据，区间为实测恢复稳态时刻至图中12秒，时间按观测响应起点对齐。真实S指令延迟仍未知；参考平台自身不计分。0.85%不是整条曲线的误差，以上条件验证不能替代独立新记录。

复现脚本及记录位于`output/load_prediction/reference_integration/`，未重新拟合现有模型，原CSV与模型指纹一致。AFC全套回归135项通过、72个子测试通过；2项神经网络测试因当前环境缺少可用PyTorch跳过。本阶段没有网络训练，实际加工样本的完整联调仍需真实机床与工艺配置。

本轮复用已有单参数校正与背景任务机制，避免新增函数拟合或网络（KISS、YAGNI）；把参考校验集中在`base_reference.py`并与界面、样本编排分离（DRY、SOLID）。主要难点是不同文件各自从0秒开始，通过显式共享时间轴及同文件前缀屏蔽解决。下一步应在独立的新会话中重新提取参考，验证该校正流程，并分别复核稳态功率和恢复时间。

“末1秒”指**已经稳定后的取样窗口**，并不表示主轴只需空转1秒。只有功率和转速并不能可靠判断是否切削，用户需明确确认该窗口为空载。

参考还会检查数据完整性、正转速范围、稳速程度、功率漂移和波动。相对模型偏移超过20%时拒绝直接校正，提示重新检查工况；该20%是适用性检查，不是新增精度验收容差。原来的功率和时间验收阈值均未放宽。
