# 预测小缺口连接规则

生效日期：2026年10月29日。规则版本：`afc.prediction_short_gap_bridge.1`。

原工艺点映射到预测曲线后，若出现很短的位置缺口，按用户要求直接连接。阈值是两侧原网格有效预测点在NC几何中的跨度严格小于 **0.05 mm**，使用`segment_mm`计算，不用四舍五入后的累计行程判断。

## 连接方式

- 两侧点必须属于同一NC物理行、执行实例和有效序列，缺点位于两者之间。允许空载／切削接触状态发生变化。
- 按位置比例线性插值，基础功率、切削功率、总功率及上下界同时处理。原来有效的预测不改。
- 等于或超过0.05 mm、缺少两端、跨序列或端点存在冲突时不连接；不外推，也不使用新补点继续连接更长缺口。
- 每个补点记录原锚点、跨度、插值比例和规则版本。剩余缺值仍保留不可用状态；缺失切削点的区间输出仍按原规则报错。

这是预测输出的近似处理。实测数据、对齐标签、有效监督范围、训练数值代码和模型权重均不因此变化；连接后的点不能当作新增实测数据或新的模型验证结论。
