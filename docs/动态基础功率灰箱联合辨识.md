# 动态基础功率：一阶/二阶灰箱联合辨识

日期：2026-09-28。使用三份现有空载 CSV 完成非神经网络标定、整文件留出比较和候选保存。原始文件只读，不执行切削负载网络训练。

## 结论

二阶惯性驱动灰箱优于同类一阶模型，但没有全面超过现有事件模型。因此保留事件模型作为默认方法，灰箱结果独立保存为 `research_candidate_unvalidated`，可以在界面查询，不能作为已验证模型自动生成正式训练标签。

结果说明：这批数据中，动态驱动形式比单纯增加阶数更重要。将转速变化率乘以转速后，启动功率随转速增加的特征得到更好描述；增加第二个状态进一步改善恢复尾段。严格恢复时间误差仍未通过原来的 0.5 秒开发验收阈值。

## 模型与联合辨识

令 \(n=S/1000\)，\(S\) 单位为 r/min。比较四个预先指定的组合：一阶/二阶 × 加速度驱动/惯性驱动。

\[
u=\dot n\quad\text{或}\quad u=n\dot n,
\qquad u_+=\max(u,0),\quad u_-=\max(-u,0)
\]

\[
P(t)=f(S(t))+b_r n(t)+d_+u_+(t)-d_-u_-(t)+\sum_{j=1}^{m}x_j(t)
\]

\[
\tau_j\dot x_j+x_j=g_{j,+}u_+-g_{j,-}u_-,\qquad m\in\{1,2\}
\]

- `f(S)`：训练文件的末段稳态功率中位数和分段线性插值，沿用事件模型读取及提取规则；不是与全部参数同时优化的自由曲线。
- `τ、d、g`：所有训练文件共享，用有边界的稳健最小二乘联合辨识；启动、制动增益分别估计，时间常数共享。
- `b_r、x_j(0)`：每份训练记录分别估计的功率偏移与初始动态状态。它们不是已测温度、磨损或材料参数。
- 增益非负，时间常数默认限制在 0.005～20 秒；二阶按时间常数排序保存，便于比较。
- 两个固定初值进行优化，记录收敛、边界和未激活状态；状态增益接近零或时间常数接近时，不宣称辨识出了两个独立物理过程。
- `n·dn/dt` 是与 `ω·dω/dt` 成比例的惯性驱动量，比例由增益吸收；不将该增益直接解释为已测转动惯量。

速度采用现有 101 ms 平滑及变化率提取，低于既有稳速阈值的变化率置零，避免编码器纹波整流成持续动态功率；功率沿用 21 ms 中值滤波。拟合默认每 20 ms 取样，最终验证用原始 1 ms 时间网格逐点计算曲线误差。这里的拟合步长不代表机床插补周期。速度滤波用于离线计算，不能称为实时因果算法。

## 初始状态与防止数据泄漏

联合训练时可以读取训练文件完整功率。留出文件分开评价：

1. **实测转速输入**：共享参数仅用另外两份文件辨识；留出功率只用于评分。记录起点使用已稳定的零动态状态假设，偏移为零。这是加工后实测转速驱动，不能当成加工前预测。
2. **此前空载初始化＋实测转速**：只使用留出文件首个正转速平台结束前的已完成空载前缀。末 1 秒必须通过现有稳定空载检查，用它确定偏移；再在固定共享参数、固定偏移下估计此前动态状态并传播到前缀终点。此后不再读取功率更新状态。首个参考档位的启动和制动均不计分。
3. **仅目标转速**：从另外两份训练文件的转速事件模板生成预期转速，再计算功率。只支持已稳定 0→S 和 S→0。其误差包含转速模板误差，但不包含未采集的控制器指令延迟。

参考状态带模型版本、来源、结束时间和前缀 SHA-256；使用时必须从相同来源的该结束时刻继续，包含全部后续转速历史，不能跳过中间运动。新增测试确认：任意修改前缀结束后的功率、转速和有效标记，均不会改变初始化结果。

没有指定初态时，前 5 倍最大时间常数标为未知；超出转速范围和未标定的低速稳态区间不作为有效功率。制动负值保留。接口可传播连续状态，但任意非零变速和中途重启尚未经过真实数据验证。

## 三文件结果

每个候选先进行三次单文件拟合诊断，再做三次“另外两文件联合辨识→留出一文件评分”，最后才用三份文件生成总体候选。共 4 个候选 × 7 次标定，每次标定有两个优化初值。单文件诊断与留出成绩分别保存，不能混用。

下表为 **输入实测转速、不给留出功率参考** 的 54 个完整事件结果。RMSE 是每折完整变速窗口 RMSE 的算术平均。事件基准与新模型用同一评分器重算，局部峰值滤波离散点口径与旧报告有小幅差异，未放宽任何验收阈值。

| 模型 | 完整变速 RMSE 均值/W | 最大峰谷相对误差 | 最大达峰谷时间误差/s | 最大恢复时间误差/s |
|---|---:|---:|---:|---:|
| 事件模型基准 | 9.17 | 5.20% | 0.097 | 2.157 |
| 一阶，加速度驱动 | 94.72 | 103.19% | 4.682 | 2.491 |
| 二阶，加速度驱动 | 94.56 | 103.09% | 4.682 | 2.535 |
| 一阶，惯性驱动 | 13.92 | 7.42% | 0.169 | 3.889 |
| 二阶，惯性驱动 | 12.97 | 6.46% | 0.127 | 2.160 |

同一二阶惯性模型的条件结果与加工前查询结果：

| 模式 | 事件数 | 完整变速 RMSE 均值/W | 最大恢复时间误差/s | 最大稳态偏差/W |
|---|---:|---:|---:|---:|
| 二阶＋此前空载初始化＋实测转速 | 48 | 10.53 | 2.332 | 8.32 |

参考校正后平台偏差明显减小，但不能据此宣称恢复时间已改善。仅目标转速时，二阶最大达峰谷时间误差约 0.373 秒，超过 0.15 秒原阈值；实测转速成绩不能代替这一结果。

全部文件拟合的二阶惯性候选时间常数约为 **0.0585 秒、3.223 秒**；制动的慢状态增益接近零。这是模型拟合结果，不是独立测得的机床固有时间常数。相同训练输入下，二阶单文件完整变速 RMSE 仍约为 10.1～10.4 W，说明残余误差并不全来自跨文件状态差异。

自动替换判据预先固定为：各输入模式通过原有阈值，且峰值、达峰时间、恢复时间、稳态偏差和完整变速 RMSE 不劣于对应事件基准。本次无候选满足，因此不替换。四种候选是在同三份数据上比较得出，仍需要新记录独立确认，不能把模型选择成绩当作最终泛化精度。

## 界面及接口

研究版“负载预测 → 基础功率”新增：

1. **一阶/二阶联合辨识对比**：先导入三份空载 CSV，可审核平台；后台完成四种组合、单文件诊断及留出比较，支持取消。结果写到独立目录。
2. **灰箱候选转速查询**：选择模型、目标转速和初始转速，显示候选功率曲线、峰谷值、达峰谷时间、稳态功率和恢复时间。默认选择二阶惯性候选供检查，不意味着它已通过验收。
3. **加载灰箱候选**：读取独立 JSON 并验证参数与版本。
4. **灰箱标定设置**：调整拟合步长、迭代次数及参数边界，不改变基础功率验收口径。

灰箱候选与原基础功率模型使用不同容器；取消、失败或加载研究候选均不会覆盖原有效模型。此前空载动态初始化目前通过独立 API 和验证流程使用，界面灰箱转速查询仍采用已稳定初态、零偏移总体模型。

```python
from project.load_prediction import (
    compare_greybox_models, GreyBoxModel,
    initialize_greybox_state, predict_greybox, predict_greybox_event,
)

comparison = compare_greybox_models(records)
model = comparison["models"]["order2_inertial"]
model.save(output_path)
model = GreyBoxModel.load(output_path)
query = predict_greybox_event(10000, model)

# completed_idle_end_s 必须位于当前会话已完成空载平台末端。
state = initialize_greybox_state(
    record, model, end_s=completed_idle_end_s, no_load_confirmed=True,
)
use = record.time_s >= state.end_s
prediction = predict_greybox(
    record.time_s[use], record.values["spindle_speed_rpm"][use],
    model, state=state, source=record.source,
)
```
